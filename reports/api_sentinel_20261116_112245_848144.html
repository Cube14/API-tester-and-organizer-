What happened?

The legitimate owner successfully retrieved this object, and a different account also retrieved the same requested resource. Both responses identified the same legitimate owner.

Technical evidence

  • Cross-account HTTP status: 200
  • Legitimate-owner baseline: Verified
  • Ownership mismatch: Yes
